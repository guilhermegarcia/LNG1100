# Organisation des données

## `base/`

Jeux de données disponibles dès le début du cours. Les chapitres et les scripts qui les utilisent peuvent donc supposer qu'ils se trouvent déjà dans le projet.

## `supplementaires/`

Jeux de données introduits au fil du trimestre. `francais.csv` est utilisé pendant la révision de fin de trimestre.

Les fichiers `questionnaire.csv` et `questionnaire2.csv` ne sont pas fournis au début du cours : ils sont générés en classe à partir des réponses de la cohorte dans Microsoft Forms, puis déposés dans ce dossier sous ces noms. Les scripts et le livre emploient déjà les chemins correspondants.

Les chemins utilisés dans le matériel du cours suivent la forme `donnees/base/fichier.csv` ou `donnees/supplementaires/fichier.csv`.
